# Coffee-shop-priskalkulator
Dette programmet kan brukes til å regne ut prisen til bestillinger.
Du kan sette type kaffe, størrelse, om de vil ta kaffe med seg og enkelt forandre prisen på valgene.

### Hvordan legge til ting
På toppen av koden kan du se tre lister en med kaffeer og en med kaffe størrelser.
Tallet som kaffeen eller størrelsen har er prisen for det valget.
Det er bare å skrive det sånn "kaffe/størrelse navn": pris.

### Hvordan bruke programmet
1. Du må først ha python installert.
2. Så må du trykk på spill av kanappen i høyre hjørne.
3. Du får et spørsmål i terminalen og det kan du svare på i terminalen.
